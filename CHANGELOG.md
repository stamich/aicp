# Changelog

All notable changes to AICP are documented here.

## [0.1.0] - 2026-09-12

### Added

- Initial Adaptive Intent Control Plane workspace.
- `aicp/v1alpha1` YAML intent schema.
- Canonical `IntentIr`.
- Semantic validation.
- Static engine capability registry.
- Deterministic three-strategy planner.
- Hard constraint filtering and weighted scoring.
- Explainable plan selection.
- Adapter SPI.
- Mock AdaptiveDB, ACE and GraphNet adapters.
- Transaction-like execution orchestration with best-effort rollback.
- Telemetry and assurance model.
- Replan recommendation on intent violation.
- CLI and standalone demo.
- Criterion benchmark suite.
- Rustdoc comments for public APIs.
